This project is a real-time shipment tracking system built using Spring Boot, WebSocket (STOMP), and SockJS.

It allows users to create shipments, track their status in real-time, and receive live updates via WebSocket.

Features:
- Create and manage shipments
- Track shipment status updates in real-time
- WebSocket integration using STOMP protocol
- RESTful APIs for shipment operations
- Live notifications for status changes
- Separation of global and per-shipment topics

Tech Stack:
- Java 22
- Spring Boot
- Spring WebSocket (STOMP)
- SockJS
- JPA / Hibernate
- MySQL (or your DB)

This project demonstrates backend architecture, real-time communication, and event-driven design.
